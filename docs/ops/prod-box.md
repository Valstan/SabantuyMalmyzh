# Прод-бокс: что живёт вне git и как это устроено

Заметки о боксе Сабантуя (jino cloud, Ubuntu 24.04, SSH-хост `sabantuy`), чтобы
не переоткрывать это каждой сессией. Всё ниже — **вне репозитория**: правкой кода
не меняется.

## HTTPS и редирект http→https (директива brain 2026-07-12)

- **Сертификаты выдаёт панель Джино** (Домены → SSL), а **не** `certbot` на боксе.
  На момент 2026-07-12 стояли: `сабантуймалмыж.рф` (с 28.05) и wildcard
  `*.сабантуй.вмалмыже.рф` (с 28.06) — https 200 работал и до редиректа.
- **Редирект включён 2026-07-12** сессией соседа по боксу (KazanskayaMalmyzh) по
  решению владельца. Живёт в `/etc/nginx/conf.d/sabantuy.conf` (бэкап рядом:
  `…conf.bak-2026-07-12`), вне git.
- Условие редиректа — **по заголовку `X-Forwarded-Proto`**, не по `$scheme`:

  ```nginx
  if ($http_x_forwarded_proto = "http") { return 301 https://$host$request_uri; }
  ```

  Внешние 80/443 терминирует прокси Джино, внутрь **всегда** приходит `http` →
  условие на `$scheme` даёт бесконечную петлю. Грабля — G150 в библиотеке мозга
  ([`GOTCHAS.md`](../../../brain_matrica/cross-project-ideas/GOTCHAS.md)).
- **CI-смоуки не задеты:** `deploy-prod.yml` бьёт `http://127.0.0.1:3000` мимо
  nginx, а localhost без `X-Forwarded-Proto` не редиректится.
- 301 со старого домена на новый — по-прежнему наш `web/src/middleware.ts`
  (host-based, постранично), а не nginx.

## Соседи по боксу

На боксе живёт не только Сабантуй (сессии соседних проектов могут править
`/etc/nginx/conf.d/*`). При диагностике «сайт отдаёт не то» проверять, не менялся
ли nginx-конф: `ls -la /etc/nginx/conf.d/` — бэкапы соседи оставляют рядом.

## Прочее, что вне git

| Что | Где | Кто пишет |
|---|---|---|
| Секреты приложения | `/etc/sabantuy/sabantuy.env` (root:0640) | воркфлоу `apply-*-secrets` (ярус `ask`) |
| Персистентная медиатека | `shared/media` (симлинк, `MEDIA_DIR`) | приложение + `recover-fotostena-media.yml` |
| systemd-юнит | `sabantuy.service` | настраивался при M3 |
| nginx | `/etc/nginx/conf.d/sabantuy.conf` | вручную/соседи (см. выше) |

Read-only диагностика бокса — `probe-prod.yml` (метрики/логи/диск) и
`probe-schema.yml` (инвентарь схемы БД). SSH напрямую с dev-машины режется (G8) —
ходить воркфлоу с раннера.
