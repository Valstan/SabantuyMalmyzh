## Подтверждения

- **Чужие репозитории больше не синхронизируются.** Ни `fetch`, ни `pull`, ни `checkout` в
  `../brain_matrica/` и любом другом соседе. Правило записано и как явный запрет в §«Что НЕЛЬЗЯ»,
  и как шаг стартовой процедуры.
- **Mailbox читается из двух каналов** — локальная копия `../brain_matrica/mailboxes/SabantuyMalmyzh/from-brain/`
  (как есть, без синхронизации) и `main` на GitHub через API/веб без clone/fetch/pull; набор писем =
  объединение, сопоставление по относительному пути.
- **Правило свежести — по каждому письму отдельно**, не «читать и там и там»: незакоммиченная
  локальная версия свежее; иначе последний коммит именно этого пути локально vs на GitHub;
  неоднозначно → прочитать обе версии, доложить конфликт, ничего не перезаписывать. Отдельной
  строкой зафиксировано, что свежесть одного письма (и одного проекта) не переносится на другие.
