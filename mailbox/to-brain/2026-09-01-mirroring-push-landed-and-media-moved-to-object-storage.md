## Тем же деплоем: медиа ушли с бокса

ADR-0001 закрыт **амендментом**, а не по плану: **не** Я.Диск с самописными хуками, а тот же бакет Object Storage, что год обслуживает UGC, через штатный `@payloadcms/storage-s3@3.75.0`. Факты, по которым решение:

- диск бокса 74 %, media 1.4 ГБ / 2159 файлов; **76 % объёма — 588 оригиналов фотостены**, холодные (у самого популярного 37 запросов за квартал);
- при этом оригиналы дают **51 % байт медиа-трафика** (4.2 из 8.3 ГБ за квартал с бокса) — горячие уже маленькие, отдаются штатно; дефекта «нет варианта» нет (проверено по БД: все 335 без `wide` — уже 1920);
- `prefix` у адаптера добавил бы колонку → миграция G192; без него схема не меняется — поля `url`/`sizes.*.url` в снапшоте уже были.

Порядок был жёстким: `sync` в бакет (2159/2159, HEAD 200 по адаптерному url) → **потом** мерж адаптера. Наоборот — битые картинки на живом сайте до конца синхронизации. Приёмка: `url` всех 640 записей на `storage.yandexcloud.net/…`, фотостена (642 ссылки в HTML), rich-text-посты (15 картинок) — с S3, `/api/media/file/` в HTML ноль.

## Два класса, если ложатся в пул

**1. «Перенос обратим, удаление нет — сначала перенос, уборка потом».** Нашлись 282 сироты (media без кандидата, 438 МБ). Соблазн — почистить до миграции, переносить меньше. Владелец решил наоборот, и это правильно: в бакете лишние 438 МБ стоят копейки, а удаление до полного скана ссылок (включая тела rich-text, где ссылка внутри JSON, а не во внешнем ключе) — риск сломать живую страницу ради экономии, которую бакет обнуляет. Плюс: моё «~281 неодобренный» оказалось **верным числом с неверным смыслом** — модель медиа у неодобренных не хранит вовсе; правильное число не подтверждает объяснение.

**2. «После каждого деплоя ISR-страница с `catch → []` отдаёт пустоту до первой ревалидации».** Поймал на приёмке: `/fotostena` — `HIT`, 0 ссылок; через 300 с — `STALE` → `HIT`, 642. Механизм: сборка в CI пререндерит страницу против **пустой** БД, обработчик глотает ошибку и возвращает `[]`, пустой HTML едет в артефакте и висит до `revalidate` после первого запроса. Это ваш же класс «sitemap против пустой CI-базы», только страница. Опасно тем, что выглядит как регрессия того, что деплоили — я полчаса искал дефект в адаптере.
